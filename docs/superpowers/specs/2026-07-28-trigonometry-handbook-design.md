# 常见三角函数与反三角函数交互式速查手册设计

**日期：** 2026-07-28

**状态：** 已确认

**目标项目：** DevTools（Vue 3 + Vite + Vue Router）

## 1. 背景与目标

在现有 DevTools 首页中增加“数学”分类，并新增“三角函数手册”工具卡片。进入卡片后展示一个完整、响应式、可交互的中文单页教学手册，面向正在学习大学微积分的初学者。

页面只涵盖三角函数与反三角函数，不加入一般函数理论、复杂积分、数列、多元微积分、线性代数、博客、登录、评论、课程推荐等内容。

主要目标：

- 通过真实绘制的函数图像帮助用户理解函数性质。
- 快速查询定义域、值域、单调性、周期、导数、渐近线等信息。
- 解释反函数的主值范围以及原函数限制后的图像关系。
- 在桌面端和移动端提供清晰、可访问的教学体验。
- 以专用页面接入现有站点，不改变已有工具的布局和行为。

全文默认使用弧度制，并在页面顶部明确标注 `k ∈ Z`。

## 2. 项目集成边界

现有项目采用工具注册表、通用 `ToolView` 和少量专用视图。三角函数手册不适合“输入—执行—输出”模型，因此使用专用视图接入。

集成方式：

- 在工具注册表中新增 `math` 分类。
- 注册 ID 为 `trigonometry` 的工具卡片。
- 新增固定路由 `/tool/trigonometry`，并放在动态 `/tool/:id` 之前。
- 路由采用懒加载，KaTeX 和手册代码不进入首页初始代码块。
- 路由通过 `meta` 标记为宽版页面；`App.vue` 仅在该路由放宽内容区，其他页面继续保持现有 960px 布局。
- 不修改现有 `ToolView`、`InputBox`、`OutputBox`、`ToolCard` 和收藏逻辑。
- 不重构与本功能无关的代码。
- 当前工作区已有的 JSON 格式化改动属于独立工作，不纳入本功能提交。

## 3. 技术方案

采用以下技术组合：

- Vue 3 专用视图。
- 新增子系统使用 TypeScript，现有 JavaScript 文件不迁移。
- KaTeX 本地安装并由 Vite 打包，禁止使用 CDN。
- 原生 SVG 绘制坐标系、曲线、关键点和渐近线。
- Vitest 测试数学目录、采样器、坐标格式化和反函数关系。
- 不引入 ECharts、Plotly、Pinia或后端服务。

选择 SVG 而不是通用绘图库，主要是为了精确控制 π 刻度、曲线分支、渐近线、教材式视觉、键盘控件和移动端呈现。

KaTeX 使用规则：

- 通过源码导入 `katex/dist/katex.min.css`，由 Vite 重写字体资源路径。
- 使用默认安全模式，固定 `trust: false`。
- 只渲染项目内可信公式，不接受任意用户 LaTeX 输入。
- 渲染失败时显示原始公式文本。
- 长公式只允许公式容器局部滚动，不允许整页横向溢出。
- 构建后验证 GitHub Pages `/my-tools/` 基础路径下不存在字体 404。

## 6. 收录函数与内容基准

### 6.1 基础三角函数

#### sin x

- 定义域：`R`
- 值域：`[-1, 1]`
- 奇函数，最小正周期 `2π`
- 零点：`x = kπ`
- 最大值 `1`：`x = π/2 + 2kπ`
- 最小值 `-1`：`x = -π/2 + 2kπ`
- 递增：`[-π/2 + 2kπ, π/2 + 2kπ]`
- 递减：`[π/2 + 2kπ, 3π/2 + 2kπ]`
- 在 `R` 上连续
- 导数：`cos x`
- 无竖直或水平渐近线

#### cos x

- 定义域：`R`
- 值域：`[-1, 1]`
- 偶函数，最小正周期 `2π`
- 零点：`x = π/2 + kπ`
- 最大值 `1`：`x = 2kπ`
- 最小值 `-1`：`x = π + 2kπ`
- 递增：`[(2k-1)π, 2kπ]`
- 递减：`[2kπ, (2k+1)π]`
- 在 `R` 上连续
- 导数：`-sin x`
- 无竖直或水平渐近线

#### tan x

- 定义域：`R \ {π/2 + kπ}`
- 值域：`R`
- 奇函数，最小正周期 `π`
- 零点：`x = kπ`
- 在每个 `(-π/2 + kπ, π/2 + kπ)` 上严格递增并连续
- 无递减区间，无最大值和最小值
- 竖直渐近线：`x = π/2 + kπ`
- 导数：`sec²x`

#### cot x

- 定义域：`R \ {kπ}`
- 值域：`R`
- 奇函数，最小正周期 `π`
- 零点：`x = π/2 + kπ`
- 在每个 `(kπ, (k+1)π)` 上严格递减并连续
- 无递增区间，无最大值和最小值
- 竖直渐近线：`x = kπ`
- 导数：`-csc²x`

#### sec x

- 定义域：`R \ {π/2 + kπ}`
- 值域：`(-∞, -1] ∪ [1, +∞)`
- 偶函数，最小正周期 `2π`
- 无零点，无全局最大值或最小值
- 局部最小值 `1`：`x = 2kπ`
- 局部最大值 `-1`：`x = π + 2kπ`
- 递减：`(-π/2 + 2kπ, 2kπ)`、`(π + 2kπ, 3π/2 + 2kπ)`
- 递增：`(2kπ, π/2 + 2kπ)`、`(π/2 + 2kπ, π + 2kπ)`
- 连续区间：每个 `(-π/2 + kπ, π/2 + kπ)`
- 竖直渐近线：`x = π/2 + kπ`
- 导数：`sec x tan x`

#### csc x

- 定义域：`R \ {kπ}`
- 值域：`(-∞, -1] ∪ [1, +∞)`
- 奇函数，最小正周期 `2π`
- 无零点，无全局最大值或最小值
- 局部最小值 `1`：`x = π/2 + 2kπ`
- 局部最大值 `-1`：`x = 3π/2 + 2kπ`
- 递减：`(2kπ, π/2 + 2kπ)`、`(3π/2 + 2kπ, 2π + 2kπ)`
- 递增：`(π/2 + 2kπ, π + 2kπ)`、`(π + 2kπ, 3π/2 + 2kπ)`
- 连续区间：每个 `(kπ, (k+1)π)`
- 竖直渐近线：`x = kπ`
- 导数：`-csc x cot x`

基础三角函数的代表性关键坐标至少包括：

- sin：`(-π, 0)`、`(-π/2, -1)`、`(0, 0)`、`(π/2, 1)`、`(π, 0)`。
- cos：`(-π, -1)`、`(-π/2, 0)`、`(0, 1)`、`(π/2, 0)`、`(π, -1)`。
- tan：`(-π/4, -1)`、`(0, 0)`、`(π/4, 1)`。
- cot：`(π/4, 1)`、`(π/2, 0)`、`(3π/4, -1)`。
- sec：`(-π, -1)`、`(0, 1)`、`(π, -1)`、`(2π, 1)`。
- csc：`(-π/2, -1)`、`(π/2, 1)`、`(3π/2, -1)`。

图像按目录中的分支生成规则绘制，任何单调区间或连续区间都不得跨越未定义点。

### 6.2 主要反三角函数

#### arcsin x

- 原函数限制：`sin x` 限制在 `[-π/2, π/2]`
- 定义域：`[-1, 1]`
- 主值范围：`[-π/2, π/2]`
- 奇函数，严格递增，无周期
- 关键点：`(-1, -π/2)`、`(0, 0)`、`(1, π/2)`
- 导数：`1 / √(1-x²)`，其中 `-1 < x < 1`
- 在 `[-1, 1]` 上连续
- `x = ±1` 处导数不存在且具有竖直切线
- 最小值 `-π/2`：`x = -1`；最大值 `π/2`：`x = 1`

#### arccos x

- 原函数限制：`cos x` 限制在 `[0, π]`
- 定义域：`[-1, 1]`
- 主值范围：`[0, π]`
- 非奇非偶，严格递减，无周期
- 关键点：`(-1, π)`、`(0, π/2)`、`(1, 0)`
- 导数：`-1 / √(1-x²)`，其中 `-1 < x < 1`
- 在 `[-1, 1]` 上连续
- `x = ±1` 处导数不存在且具有竖直切线
- 最大值 `π`：`x = -1`；最小值 `0`：`x = 1`
- 关系：`arccos x = π/2 - arcsin x`

#### arctan x

- 原函数限制：`tan x` 限制在 `(-π/2, π/2)`
- 定义域：`R`
- 主值范围：`(-π/2, π/2)`
- 奇函数，严格递增，无周期
- 关键点：`(-1, -π/4)`、`(0, 0)`、`(1, π/4)`
- 水平渐近线：`y = -π/2`、`y = π/2`
- 导数：`1 / (1+x²)`
- 在 `R` 上连续，无最大值和最小值

#### arccot x

- 明确采用主值范围 `(0, π)`
- 原函数限制：`cot x` 限制在 `(0, π)`
- 定义域：`R`
- 主值范围：`(0, π)`
- 非奇非偶，严格递减，无周期
- 关键点：`(-1, 3π/4)`、`(0, π/2)`、`(1, π/4)`
- 当 `x → -∞` 时，`y → π`
- 当 `x → +∞` 时，`y → 0`
- 水平渐近线：`y = π`、`y = 0`
- 导数：`-1 / (1+x²)`
- 关系：`arccot(-x) = π - arccot x`
- 在 `R` 上连续，无最大值和最小值

四个主要反三角函数都必须直接显示主值范围和对应原函数的限制区间。

### 6.3 补充内容

`arcsec x` 和 `arccsc x` 只放在“补充内容”中，不加入主要反三角函数筛选和默认比较。页面明确说明不同教材可能采用不同的主值范围约定，不给未声明约定的公式制造唯一答案印象。

## 8. 主图选择与坐标规则

- 默认选择 `sin x`。
- 三角函数和反三角函数分区分别保存选择状态。
- 每个分区最多同时比较 4 个函数。
- 主图不跨分区混合函数；原函数与反函数跨类比较由反函数关系模块承担。
- 无函数选中时显示空状态和“恢复默认”按钮。

坐标规则：

- 三角函数默认横轴范围为 `[-2π, 2π]`，横轴使用 π 倍数刻度。
- 仅包含 sin、cos 时使用适合 `[-1, 1]` 的紧凑纵轴。
- 包含 tan、cot、sec、csc 时使用较大的默认纵轴裁剪范围，但不得把裁剪边界表示为函数最值。
- 反三角函数横轴表示普通实数输入，使用普通实数刻度。
- 反三角函数纵轴表示角度，使用 π 倍数刻度。
- 无法可靠表示为常见 π 分数时才显示小数。

## 9. SVG 绘图与分支采样

每个连续分支生成独立的 SVG path。禁止把整个可视范围采样为一条 polyline 后仅依靠相邻点差值判断断裂。

分支规则：

- tan：按 `(-π/2 + kπ, π/2 + kπ)` 生成。
- cot：按 `(kπ, (k+1)π)` 生成。
- sec：按相邻的 `π/2 + kπ` 之间生成。
- csc：按相邻的 `kπ` 之间生成。
- 反三角函数按各自定义域裁剪。

采样器要求：

- 开区间端点保留与当前缩放级别相关的安全距离。
- 丢弃 `NaN`、`Infinity` 和非有限坐标。
- 对超出可视纵轴的线段进行裁剪。
- 单个分支失败不影响其他分支。
- 缩放和平移后重新计算可见分支和采样密度。
- SVG path 字符串中不得出现非有限数值。

交互规则：

- 鼠标滚轮围绕指针缩放，拖动平移。
- 同时提供键盘可操作的放大、缩小和重置按钮。
- 桌面端悬停显示函数名和坐标，点击可固定提示。
- 移动端点击或拖动十字准线查看坐标。
- 关键点、零点和极值点使用独立标记。
- 渐近线使用虚线和文字标签。
- 颜色、线型和曲线标签共同区分函数。

## 10. 反函数关系模块

模块提供 arcsin、arccos、arctan、arccot 四组关系：

- sin 限制在 `[-π/2, π/2]` 后与 arcsin 对应。
- cos 限制在 `[0, π]` 后与 arccos 对应。
- tan 限制在 `(-π/2, π/2)` 后与 arctan 对应。
- cot 限制在 `(0, π)` 后与 arccot 对应。

提供三个独立开关：

- 显示或隐藏受限后的原函数。
- 显示或隐藏对应反函数。
- 显示或隐藏对称轴 `y = x`。

对应关系、限制区间和主值范围从统一目录读取，不在组件内重复定义。

## 11. 易错点

必须包含：

1. `sin⁻¹x` 通常表示 `arcsin x`，不表示 `1/sin x`。
2. `1/sin x = csc x`。
3. `1/cos x = sec x`。
4. 反三角函数本身不具有周期性。
5. 求反函数时定义域和值域交换。
6. `arcsin(sin x) = x` 只在 `x ∈ [-π/2, π/2]` 时直接成立。
7. `arccos(cos x) = x` 只在 `x ∈ [0, π]` 时直接成立。
8. `sin(arcsin x) = x` 要求 `x ∈ [-1, 1]`。
9. `tan(arctan x) = x` 对所有实数成立。
10. 反函数与倒数函数是完全不同的概念。

部分条目使用原生 `details/summary` 展开例题。例如：

`arcsin(sin(2π/3)) = π/3`，因为 `2π/3` 不在 arcsin 的主值范围内，而 `sin(2π/3) = sin(π/3)`。

## 12. 主题与视觉规范

- 使用克制的学术配色、细边框和清晰层级。
- 不使用大面积渐变、强阴影或无意义装饰。
- 图像是页面视觉重点。
- 默认跟随系统深浅主题，并提供手动切换。
- 手动选择保存在独立的 `trigonometry-theme` 配置中。
- 主题变量限定在手册页面容器内；现有工具页面保持当前视觉。
- 如需覆盖页面外背景，使用手册页面自身的全视口背景层，不永久修改全局主题。
- 离开手册页面后不改变其他工具的颜色状态。

## 13. 可访问性

- 使用 `main`、`nav`、`section`、`table`、`fieldset`、`legend`、`details` 等语义元素。
- 函数选择使用真实复选框。
- 显示开关使用明确的选中状态和 `aria-pressed`。
- SVG 使用 `role="img"`、标题、描述和可访问名称。
- 图像下方提供当前函数、视口、渐近线和关键点的文字摘要。
- 悬停提示不是获取关键信息的唯一方式。
- 所有交互控件均可通过键盘操作，并具有明显焦点样式。
- 尊重 `prefers-reduced-motion`。
- 移动端使用属性列表代替宽表格。

## 14. 异常与降级策略

- KaTeX 渲染失败时显示原始公式文本。
- 达到 4 个函数上限时在选择器附近提示。
- 无函数选中时显示空状态。
- SVG 容器尺寸为零时等待重新测量，不生成路径。
- 非有限采样点直接丢弃。
- 单个函数或分支计算失败不影响其他曲线。
